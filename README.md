

1. 何を作ろうと思ったか

仮眠前と本睡眠前に使う、睡眠時間の目安を出すWebツールを作りました。

仮眠前には、前回の本睡眠時間や起床からの経過時間をもとに、現在の活動限界を確認し、どの程度の仮眠を取るとよいかを表示します。
本睡眠前には、前回の睡眠不足や当日の仮眠記録をもとに、今夜どれくらい寝るべきかを表示します。

単なる睡眠記録アプリではなく、仮眠前と本睡眠前の判断に使えるツールにすることを目指しました。

 2. なぜか

自分は、仮眠を取るべきか、取るなら何分くらいがよいのかを毎回感覚で判断していました。

特に、夜に作業したい時は、朝や昼と比べて集中力や判断力が落ちやすく、「今の状態で作業を続けるべきか」「少し仮眠した方がよいのか」を迷うことがありました。

ChatGPTに相談すれば考えることはできますが、そのたびに「前回何時間寝たか」「今日何分仮眠したか」「今何時か」を説明する必要があり、手軽ではありません。
また、既存の睡眠記録アプリは記録が中心で、自分が知りたい「今どれくらい寝るべきか」に直結しにくいと感じました。

そこで、記録自体を目的にするのではなく、仮眠前と本睡眠前にすぐ判断できるツールにしました。

差別化としては、 ChatGPTよりも毎回説明しなくてよい、 既存アプリよりも記録ではなく判断に寄せる、数字入力ではなく日付や時刻を選択式にして手軽に使える、設定を増やしすぎず自分用に調整できる最低限の式にするといった点を意識しました。

 3. 生成AIとのやり取り

制作にはChatGPTを使用しました。

まず、自分が日常で感じている小さな不便を整理しました。その中で、睡眠や仮眠について「何時間寝たかを記録するだけではなく、仮眠前や本睡眠前に、どれくらい寝るべきかを判断できるものが欲しい」と考えました。

特に、ChatGPTに毎回相談する場合は、前回の睡眠時間、仮眠時間、現在時刻などをその都度説明する必要があります。その手間を減らし、選択するだけで目安が出るようにしたいと考えました。

その考えをもとに、ChatGPTには主に以下の点を相談しました。

 Webアプリとして実装できるか、 HTMLだけで記録機能を持たせられるか、仮眠と本睡眠をどう分けて考えるべきか、入力項目を増やしすぎず、使いやすくするにはどうするか、READMEに制作過程をどう整理するかという点を相談しました。

制作途中では、単なる睡眠ログ、直近7日間の集計、細かい設定を増やす案なども検討しました。しかし、自分が求めていたのは「記録を細かく残すこと」ではなく、「仮眠前・本睡眠前にすぐ判断できること」だったため、不要な機能は削りました。

最終的には、設定を「基準睡眠時間」「活動限界倍率」「仮眠の本睡眠換算率」の三つに絞りました。

また、日付や時刻は直接入力ではなく選択式にし、前日・今日・明日ボタンも付けて、操作をできるだけ軽くしました。

ChatGPTは、アイデアを整理したり、実装方法を確認したり、コードを作成・修正したりするために使いました。一方で、何を残して何を削るか、どの不便を解決するツールにするかは、自分で判断しながら進めました。


4. 詰まったところとどう乗り越えたか

一番詰まったのは、仮眠と本睡眠をどう計算するかです。

仮眠は、夜の本睡眠を完全に置き換えるものではありません。一方で、仮眠を取ることで一時的に作業しやすくなる感覚もあります。
そのため、仮眠を単純に「本睡眠の代わり」として扱うだけでは、自分の使いたい目的とズレると感じました。

そこで、仮眠の役割を2つに分けました。

1つ目は、仮眠前の判断です。
前回の本睡眠時間から活動限界を計算し、今どれくらい活動限界に近いかを見るようにしました。

2つ目は、本睡眠前の判断です。
その日に記録した仮眠を、一定割合だけ本睡眠の推奨時間に反映するようにしました。

また、制作途中でAIの提案が何度も複雑になりすぎたことも課題でした。
設定を増やせば細かく調整できますが、その分、使う前に迷ってしまいます。今回の目的は「手軽に判断できること」なので、複雑な設定は削り、最小限の3設定に絞ることで乗り越えました。

 5. 次にやるなら何を変えるか

次にやるなら、学生だけでなく会社員でも使いやすい形にしたいです。

今回のツールは、自分の生活に合わせて、夕方から夜に作業する前に仮眠を取る場面をかなり意識して作りました。そのため、活動限界時間の考え方も「起きてから夜までどれくらい動けるか」という、自分の生活リズムに寄った設計になっています。

しかし、会社員の場合は、自由に夕方や夜に仮眠を取れるとは限りません。昼休みに短く寝る、仕事後に少し休む、夜の作業に備えて仮眠するなど、使えるタイミングが人によって変わります。そのため、次に作るなら、昼休み・仕事後・夜作業前など、仮眠を取る場面を選べるようにしたいです。

また、現在は活動限界倍率を自分で設定する形にしていますが、今後は「昼寝向け」「夜作業向け」「短時間回復向け」のように、使う目的ごとに判定の考え方を切り替えられるようにしたいです。そうすれば、学生だけでなく、会社員や昼寝を活用したい人にも使いやすいツールになると思います。

さらに、実際に使った後の体感を簡単に記録できるようにし、その結果をもとに活動限界倍率や仮眠の換算率を調整できるようにしたいです。今回のツールはあくまで自分用の簡易モデルなので、使いながら自分に合う形へ近づけられるようにすることが、次の改善点だと考えています。

今回の制作では、完成度よりも「小さな不便をどうITで解決するか」を重視しました。
そのため、完璧な睡眠計算ではなく、自分の生活の中で使える判断ツールとして形にしました。
